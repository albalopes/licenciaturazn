# Dados curriculares carregados nesta versão

Esta versão substitui os registros demonstrativos das matrizes de 2012 e 2018 pelos dados extraídos dos dois PPCs fornecidos para o projeto.

## PPC 2012

- Documento: Projeto Pedagógico do Curso Superior de Licenciatura em Informática, presencial.
- Aprovação: Resolução nº 10/2012-CONSUP/IFRN, de 01/03/2012.
- Duração: 8 semestres.
- Carga horária total: 3.404 horas.
- Disciplinas obrigatórias carregadas: 37.
- Disciplinas optativas catalogadas: 14.
- Ementas, objetivos, conteúdos, metodologia, avaliação e bibliografias são carregados quando presentes no anexo do PPC.
- O PPC prevê 400h de Estágio Curricular Supervisionado (Estágio Docente), 200h de Outras Atividades Acadêmico-Científico-Culturais e TCC por monografia.

## PPC 2018

- Documento: PPC aprovado pela Resolução nº 10/2012-CONSUP/IFRN, com adequação pela Deliberação nº 21/2018-CONSEPEX, de 10/09/2018.
- Duração: 8 semestres.
- Carga horária total: 3.404 horas, sendo 2.160h de disciplinas, 244h de seminários curriculares e 1.000h de prática profissional.
- Disciplinas obrigatórias carregadas: 38.
- Disciplinas optativas catalogadas: 29.
- Ementas, objetivos, conteúdos, metodologia, avaliação e bibliografias são carregados quando presentes no anexo do PPC.
- O PPC prevê 400h de Estágio Docente, 200h de ATPA e TCC nos 7º e 8º períodos.

## Organização Didática

As páginas de aproveitamento de estudos, certificação de conhecimentos, prática profissional, TCC e integralização curricular foram preenchidas com base na Organização Didática do IFRN atualizada pela Resolução nº 110/2025-CONSUP/IFRN.

O portal mantém o link para o documento oficial, pois prazos e fluxos administrativos podem ser atualizados institucionalmente.
