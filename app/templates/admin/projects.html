Sincronizar com o SUAP

A API documentada do SUAP expõe os projetos de Pesquisa e Extensão com paginação. O endpoint documentado não oferece filtros de campus ou período; por isso o portal busca um número controlado de páginas e aplica os filtros localmente. Ensino continua disponível para cadastro manual porque não há endpoint de projetos de Ensino documentado na API fornecida.

Campus usado no filtro: Natal-Zona Norte (ZN). Se o período for antigo, aumente o número de páginas, pois a API fornece apenas page.
